# Kids Mode - Website

Landing page for **Kids Mode**, the Android app that lets a parent hand their phone to a child safely:
only the apps the parent chose, with the notification bar, settings and power menu locked away.

## Live site

<https://mbanifawaz.github.io/Kids_Mode_Website/>

## What's on the page

- English and Arabic, switched from the navbar (right-to-left layout in Arabic, choice remembered)
- Features, how it works, screenshots with a lightbox, permissions and privacy, download and contact
- Plain HTML, CSS and JavaScript, no build step. GitHub Pages serves the repo as is.

```
index.html          the page (every text has data-en / data-ar)
css/style.css       styles
js/main.js          language toggle, menu, screenshots, animations
images/             app icon, feature graphic and screenshots
```

Run it locally with `python3 -m http.server 8000` and open <http://localhost:8000>.
